# Rainbow Light（虹色ライト MOD）

ランプに付けると、光の色が虹のように回る電球を足す B42 用 MOD（試作）。

## 遊び方

1. 「虹色の電球」（`RainbowLight.LightBulbRainbow`）を作る。手に入れる方法は作ることだけ（落ちている場所はない）
   - レシピ「虹色の電球を作る」（電気）: 色付き電球を 9 色 1 個ずつ（赤・オレンジ・黄・緑・水色・青・紫・赤紫・ピンク、壊れたものは不可）、ドライバー（減らない）。覚える必要もスキルもいらない、手元で作れる
   - 色付き電球は作れず、拾うだけ。9 色がまとまって出るのは電気屋の照明の棚・大型スーパー（ギガマート）の電球の棚・季節の飾りの箱。赤と緑は技術者の道具・ラジオ工場・軍の倉庫などにも出る。ほかの色はほぼこの 3 か所だけ（本体の `ProceduralDistributions.lua`）
   - デバッグモードなら右クリック「RainbowLight (debug)」→「give rainbow bulb」でももらえる
2. 普通の電球と同じように、ランプの右クリックから電球を付け替える（本体は名前が `LightBulb` で始まるアイテムだけを電球として受け付けるので、この名前にしている）
3. ランプを点けると、2 秒で虹を一周する速さで光の色が変わる

電球の寿命は普通の電球と同じ（寿命はランプ側で数えていて、サンドボックスの「電球の寿命」に従う）。

## 仕組み

- 色を変えるのは各プレイヤーのゲームの中だけで、通信はしない。マルチでもプレイヤーごとに色の進み方は揃わない
- ランプの光の色を `setPrimaryR/G/B` で書き換え、本体と同じく `switchLight` を呼んで明かりを塗り直す。書き換えるだけでも明かりは変わるが、画面に出るまで 1〜4 秒遅れる。`switchLight` も呼ぶと約 0.1 秒
- ランプ 1 個の光の強さには上限があり（本体は色の数字を 2 倍して 1 で切る）、月明かりなど周りの明るさが混ざって色が淡くなる。濃くするため、ランプと同じマスに同じ色の光を 2 つ重ねている（`IsoCell:addLamppost`、自分のゲームの中だけ）。3 つ目は色の強さが変わらなかった
- ランプを消す・電球を抜く・離れると、重ねた光も消す

設定は `RainbowLight_Client.lua` の先頭（`PERIOD_MS` = 一周の時間、`UPDATE_MS` = 色を変える間隔、`EXTRA_LIGHTS` = 重ねる光の数、`EXTRA_RADIUS` = その半径）。

## テスト

```
python tools\light_test.py
```

テストサーバーとゲーム 1 つを起動し、ゲームが自分でサーバーに入って、ランプを置いて夜にし、色を変えて画面の明かりの数字とスクリーンショットを取る。結果は `%USERPROFILE%\PZTest_rainbow\light_test_result.txt`、スクリーンショットは `%USERPROFILE%\PZTest_rainbow\client1\Screenshots\rl_*.png`。

- サーバーの起動とゲームの自動ログインは、隣の `CheeseMaking/tools/mp_test.py` と `SkillViewer/test_server.ps1` を使う（このリポジトリ単体では動かない）
- テストはランプを置く前に、近く 20 マスの付け替えのできるランプをテスト用ワールドから片付ける
- 測っているもの: レシピ（電球なし・1 色足りないと作れず、9 色そろうと作れて 9 色が減りドライバーが残る）、色を変えてから明かりに出るまでの時間、虹色で見えた色の種類、重ねる光の数ごとの色の強さ、重さ（フレームレートと 1 フレームの処理時間）

GIF（`rainbow_light.gif`、ゲームの絵が写るのでリポジトリには入れない）は `python tools\light_test.py --gif` で一周を 25 段階に分けて撮り、`python tools\make_gif.py` で 2 秒一周の GIF にまとめる（標準ライブラリだけ）。

2026-11-06 の結果（ランプ 1 個・開発用 PC）: 今の設定でフレームレート平均 59.5、1 フレームの処理時間は虹色を止めたときと変わらない。
